1. Introduction

1.1 Brief description of the software product

FeastFleet is a full-stack web application for ordering food from nearby restaurants, with a focus on Kerala / hyperlocal delivery. Users can browse restaurants, view menus, add dishes to a cart, place orders, and follow a live delivery timeline. The product also includes AI-assisted tools: a personal food agent, budget optimizer, food memory profile, visual food search, group-order planner, ingredient/allergen predictions, and FeastBot (a floating chatbot).

The frontend is a multi-page HTML/CSS/JavaScript interface. The backend is an Express.js REST API with JWT authentication and MongoDB (or an automatic in-memory MongoDB fallback for demos).

1.2 Purpose of the system

The system is designed to:

  • Let customers discover restaurants and dishes and complete an order in a few steps.
  • Show proximity (distance and estimated time) based on a set delivery location.
  • Keep cart items consistent by limiting multi-restaurant carts to a 1 km radius.
  • Help users choose food using budget, diet, group, and allergen constraints.
  • Provide order history and live tracking after checkout.

  • Supported browsers: Google Chrome, Microsoft Edge, Firefox, or Safari (latest two versions).
  • OS: Windows 10/11, macOS, or Linux.
  • JavaScript must be enabled. A modern browser is required for geolocation UI, localStorage, and fetch APIs.
  • Default URL: http://localhost:5000 (port 5000 unless PORT is set in the environment).

3. Installation / Setup

These steps start FeastFleet on the local machine for demonstration or academic evaluation.

  1. Install Node.js from https://nodejs.org and confirm in a terminal: node -v and npm -v.
  2. Open the project folder (example): feastfleet.
  3. Install dependencies: npm install.
  4. Start the application: npm start.
  5. Wait until the console prints that the FeastFleet server is running on port 5000.
  6. Open a browser and go to http://localhost:5000 (or http://localhost:5000/index.html).
Optional seed: npm run seed loads restaurant/menu data into MongoDB. The in-memory database used for demos is seeded as part of a normal start when configured that way; if the catalog looks empty, run seed and restart.

Access without a full install: HTML files can be opened directly, but login, AI APIs, and order sync need the Express server. Always use npm start for a complete demo.

On first load you should see the brand splash screen, then the home storefront.

5. System Features / Functionalities

5.1 Set delivery location

  1. On Home, use the address field or click Detect My Location / location control.
  2. For this build, detection sets Valavoor, Kottayam.
  3. Restaurant cards then show distance (km) and estimated time.

Expected result: location label updates; nearby restaurants (for example AK Take Away, Pala) appear closer than Kochi outlets.

5.2 Browse restaurants

  1. Click Restaurants in the navbar, or Let’s Go from the home search.
  2. Use cuisine chips (All, Burgers, Asian, Indian / Kerala, Desserts, and similar) to filter.
  3. Click a restaurant card to open its menu. AK Take Away, Pala opens a dedicated menu page.
Figure 6. Restaurant catalog.

5.3 View menu and add items

  1. Open a restaurant (example: AK Take Away, Pala).
  2. Filter by category chips (Al Faham, Kerala Non-Veg, Vegetarian, Rice & Biryani, and so on).
  3. Click the orange + button on a dish to add it to the cart.
  4. The cart badge in the navbar increases.
Figure 7. Menu with prices, AI Ingredients, and add-to-cart controls.

5.4 AI ingredient and allergen prediction

  1. On a dish card, click AI Ingredients.
  2. Read predicted ingredients, dietary notes, flavor notes, match %, and allergen warnings.
  3. Optionally click Ask AI Chatbot, or Done to close.
Figure 8. AI Food Ingredient Predictor for Al Faham Chicken.

5.5 Cart and checkout

  1. Open Cart from the navbar.
  2. Change quantity with − / +, or delete an item.
  3. Optional: enter a promo code and click Apply.
  4. Review subtotal, delivery fee (typically ₹49 in the cart summary), and total.
  5. Click Place Order.

Expected result: cart clears, you are taken to live tracking, and the last order is stored for this browser session.

Items from a second restaurant are allowed only if that restaurant is within 1 km of restaurants already in the cart. Otherwise a warning toast is shown and the item is not added.
Figure 9. Cart with order summary and Place Order.

5.6 Live order tracking

  1. After placing an order, the tracking page opens automatically, or choose Track Live Order from the profile menu.
  2. Watch stages: Confirmed → Preparing → On The Way → Delivered.
  3. The countdown and rider card update in real time. Leaving and returning does not reset the timer to the full duration.
Figure 10. Live tracking timeline and rider allocation.

5.7 Order history

  1. Open the profile avatar → Order History (orders.html).
  2. Logged-in users see orders associated with their account when the API is available.
Figure 11. Order history.

5.8 Personal Food Agent

  1. From Home, open Personal Food Agent (or navbar Food Agent).
  2. Set budget, mood tags (spicy, grilled, etc.), diet, exclusions, and cuisine.
  3. Run the agent to get a constrained meal suggestion that can be added to the cart.
Figure 12. Personal Food Agent constraints panel.

5.9 Budget optimizer

  1. Open Budget Optimizer from Home.
  2. Enter group size, total budget, and meal preferences.
  3. Run optimize to get a combination of dishes that fits price and delivery constraints.
Figure 13. Budget Optimizer.

5.10 Food memory profile

  1. Open Food Memory Profile.
  2. Review patterns built from previous orders in this browser (weekday habits, price band, repetition).
  3. Use suggested variations when the profile recommends a change of dish.
Figure 14. Food Memory Profile.

5.11 Visual food search

  1. Open See Food → Find Food.
  2. Upload a food photo or pick a visual category.
  3. The system matches nearby menu items and lists the closest dishes to order.
Figure 15. Visual food search.

5.12 AI group order

  1. Open AI Group Order Agent.
  2. Set total group budget and maximum delivery time.
  3. For each person, enter name, food preference, diet, per-person budget, and optional exclusions.
  4. Add or remove members, then run the agent.
  5. Output: one recommended restaurant, a dish per person, and a per-person split. You can send the plan to the cart.
Figure 16. Group Order Agent with sample members.

5.13 FeastBot chatbot

  1. If the panel is minimized, click the circular FeastBot button (bottom-right).
  2. Use quick replies (Track Order, Food Agent, Budget Optimizer, etc.) or type a question.
  3. Minimize with the header control when you need the full page.
Figure 17. FeastBot assistant on the home page.

  1. Open Contact.
  2. Fill name, email, subject, and message, then Send Message.
  3. Use listed email support@feastfleet.com, phone +91 484 123 4567, or the FAQ accordion on the same page.

9. Logout / Exit

  1. Click the circular profile avatar (initials) at the top right.
  2. Click Log Out (red item at the bottom of the menu).
  3. The token and stored user are removed. The navbar returns to Sign In and you are sent to Home.

To leave the application entirely, close the browser tab. Stopping the backend: in the terminal where the server is running, press Ctrl+C.

Logging out does not always wipe the cart in localStorage. If you share a computer, also clear the cart or use a private window.

10. Troubleshooting / FAQ

ProblemSolution
Page will not load / connection refusedConfirm npm start is running and visit http://localhost:5000, not a random Live Server port, if the API must work.
Port 5000 already in useStop the other process or set environment variable PORT to another value and use that URL.
MongoDB not installedNo action required for a typical demo; in-memory MongoDB starts automatically.
Images or Bootstrap look brokenConnect to the internet so CDNs can load, or refresh after the network is up.
Location never changes from ValavoorThis demonstration build is configured to Valavoor, Kottayam for a consistent review.
Cannot add a second restaurantRespect the 1 km cart radius, or place the first order first.
Tracking timer looks “stuck” after refreshIt continues from elapsed time; it does not restart at 5 minutes.
Chatbot covers the pageClick the minimize (▾) control on the FeastBot header.
How do I track an order?Place an order, or open profile → Track Live Order, or ask FeastBot “Track my order”.
What payment methods?Described on Contact FAQ as cash, cards, and Apple Pay (demonstration copy).
