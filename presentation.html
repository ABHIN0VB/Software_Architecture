Problem & Solution Space

Market Pain Points vs. FeastFleet Solutions

The Traditional Aggregator Problem
  • Zero Ingredient Transparency: Diners cannot see hidden oils, raw spices, or allergen risk profiles.
  • Budget & Group Overruns: Group orders fail to satisfy disparate budgets, protein preferences, and delivery constraints.
  • Static Catalog Scrolling: Keyword search is inflexible and lacks natural-language contextual understanding.
  • Rigid Single-Vendor Carts: No multi-vendor bundling even when neighboring restaurants share the exact same location.
The FeastFleet Architectural Solution
  • AI Ingredient & Allergen Forecasting: Instant culinary breakdown into base spices, raw proteins, and dietary safety tags.
  • Constraint-Satisfaction Optimization: Automated combo generator that solves for budget, head-count, and meal structure.
  • Hyperlocal Proximity Routing: Haversine mathematical distance calculation with 1km multi-restaurant cart bundling.
  • Behavioral Food Memory: Tracks consumption patterns, provides nutritional balance charts, and repetition alerts.

System Engineering & Design Patterns

Layered MVC Architecture & Request Pipeline

Client Layer (SPA) Browser Geolocation, Cart, AI Modals, LocalStorage
REST API Gateway Express.js Router, CORS, Auth Middleware, JWT
Business Services FoodAgent, BudgetOptimizer, Haversine, IngredientAI
Data Tier Mongoose Models (User, Restaurant, MenuItem, Order)
1. Separation of Concerns
Controllers manage HTTP contracts; Services contain algorithmic reasoning and mathematical calculations; Models enforce data integrity.
2. API-First Modularity
Clean REST endpoints (/api/restaurants/nearby, /api/ai/food-agent, /api/orders) easily consumed by both web and mobile clients.
3. High Availability Fallback
Resilient client-server contract: if any AI service is unreachable, client-side fallback engines compute estimates without breaking checkout.
Platform Execution & Geolocation

Core Functional Workflows & Location Engine

1. Geolocation Discovery
Browser Geolocation API with user permission prompt, real-time latitude/longitude capture, graceful handling of permission denial, manual address search option, and dynamic Haversine distance & ETA calculation.
2. Dynamic Catalog
Cuisine-based filtering across regional catalogs. Dynamic proximity badges categorize restaurants into Near (<5 km), Medium, and Far delivery tiers with accurate fees.
3. 1km Multi-Vendor Cart
Proximity boundary check allows multi-dish bundling when neighboring restaurants share a tight 1 km physical cluster, preventing impossible multi-hub dispatches.
4. 5-Stage Live Tracking
Real-time progress pipeline (Placed → Kitchen → Driver → Out for Delivery → Delivered) with a persistent countdown timer that does not reset on page navigation.
Artificial Intelligence Integration

FeastFleet Next-Gen AI Culinary Suite

1. Personal Food Agent
Processes natural language requests: "Spicy high-protein meal under ₹250, vegetarian only." Employs explicit dietary overrides and multi-attribute menu scoring.
2. AI Budget Optimizer
Constraint-satisfaction combo generator that formulates balanced meals (main + side + beverage) fitting group headcount and maximum budget caps.
3. AI Food Memory
Behavioral analytics profiling order frequencies, nutritional balance (Veg vs. Non-Veg ratio), and proactive repetition alerts to encourage diet variety.
4. AI Ingredient Predictor
Predicts hidden culinary ingredients, spice levels, and allergens (Gluten, Dairy, Soy, Nuts) with confidence scores for transparent dining.
5. Visual Food Search
Cross-modal dish discovery matching color tones, culinary categories, and food textures with live menus.
6. FeastBot Conversationalist
Always-on conversational concierge with proactive notifications, live order status querying, and direct 1-click cart insertion.
